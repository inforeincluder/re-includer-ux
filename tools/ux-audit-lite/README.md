# UX Audit Lite — protótipo

Este diretório conterá o protótipo da ferramenta.

## Etapas de implementação
1. Definir formulário mínimo de entrada.
2. Criar motor de checklist heurístico com resultados explicáveis.
3. Gerar relatório HTML acessível.
4. Adicionar exportação/compartilhamento somente após validar o fluxo.
5. Avaliar integração com IA apenas quando houver benefício claro e custos conhecidos.

## Estado atual
Planejamento. Nenhuma auditoria automatizada está implementada ainda.
